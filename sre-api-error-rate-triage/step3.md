# Step 3: Classify Initial Severity

Use the synthetic runbook excerpt to choose an initial severity.

Run:

```bash
taskflowctl runbook
```

Ask:

- Is this SEV-1, SEV-2, SEV-3, or SEV-4?
- What evidence supports your classification?
- What evidence would make you escalate severity?
- What is the safest next step?

For this teaser, the starting hypothesis is usually SEV-3 / Medium unless broader impact evidence appears. That is not a final answer. It is an initial classification that should change if the evidence changes.
