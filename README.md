# SRE Incident Practice Labs — Free Guided Teasers

This repo contains clean-room public teaser scenarios for the SRE Incident Practice Labs product line.

## Clean-Room Statement

All scenarios, services, alerts, metrics, logs, timestamps, and notes in this repo are fictional and synthetic. They are not based on, copied from, or intended to represent any real organization, private system, incident, dashboard, ticket, chat message, runbook, or proprietary architecture.

## What This Free Scenario Teaches

The `sre-api-error-rate-triage` scenario helps learners practice first-response SRE triage for an API error-rate alert. The learner acts as an on-call responder for the fictional TaskFlow Demo `api-service`.

The teaser focuses on:

- Reading an alert.
- Inspecting synthetic metrics and log excerpts.
- Separating symptoms from root cause.
- Classifying initial severity.
- Drafting a first stakeholder update.
- Choosing the next investigation step.

## What Is Intentionally Not Included

This public teaser does not include:

- Paid answer keys.
- Completed postmortems.
- Portfolio guide content.
- Kubernetes manifests.
- Application code.
- Dockerfiles.
- Terraform, AWS, EKS, Grafana, Prometheus, AI assistant, VS Code server, Coder, or hosted-service files.
- Real incidents, real logs, real dashboards, tickets, chat messages, private runbooks, or proprietary material.
